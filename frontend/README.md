# Car Inventory Hub

Create a modern and beginner-friendly frontend for a Car Dealership Inventory Management System.

Create these pages:

1. Login/Register page

2. Customer vehicle inventory page

3. Admin dashboard

The frontend should have:

- Clean modern design

- Navigation bar

- Vehicle cards/table

- Search and filter

- Login and registration forms

- Purchase button

- Admin add, edit, delete and restock features

- Logout button

- Responsive design

Use a professional car dealership theme.

IMPORTANT:

I already have a working FastAPI backend.

Do NOT create a new backend.

Do NOT create a new database.

The frontend will connect to my existing FastAPI REST API later.
